# SkillBuilder

A private-style learning app for communication, interviews, English fluency, tech-rep careers and more. Runs entirely in the browser; progress, streaks and recordings stay in your own browser storage.

- 38 courses and 198 lessons, each with deep material, a mentor note, a Taglish explanation and memory aids, plus a Toolkit, interview simulator, answer bank, job tracker, call roleplay, listening drills, progress report and offline install
- Daily reading, daily activity, streaks with freezes, spaced-repetition review, journal
- Speaking studio with mock interviews (recordings never leave your device)
- Keyboard friendly: press `?` for shortcuts

Open `index.html` locally or visit the GitHub Pages site.
